# FastAPI SQLite CRUD Documentation

FastAPI SQLite CRUD Example is a production-minded backend portfolio project built with FastAPI, SQLAlchemy, SQLite, and JWT authentication. It demonstrates how to structure a small but realistic REST API with authentication, validation, testing, Docker support, and published documentation.

This documentation is intended for recruiters, developers, and collaborators who want to understand what the project does, how it is organized, and how to run or extend it locally.

## What this project demonstrates

- REST API development with FastAPI.
- SQLite persistence with SQLAlchemy ORM.
- JWT-based authentication for protected endpoints.
- Pydantic schemas for validation and serialization.
- Layered backend structure with routers, CRUD helpers, services, and configuration.
- Automated testing with Pytest.
- Docker-based local setup.
- Documentation published with MkDocs and Material for MkDocs.
